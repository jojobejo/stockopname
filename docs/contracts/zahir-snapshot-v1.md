# Kontrak bersama Zahir snapshot v1

Exporter dan importer harus memakai dokumen versi ini. JSON UTF-8 berupa satu objek dengan field wajib schema_version string "1", source_system "ZahirDigital", source_instance identitas stabil, snapshot_id UUID, exported_at ISO 8601 dengan zona waktu, snapshot_type "full", scope identitas cakupan stabil, complete boolean true, row_count integer identik jumlah rows, dan rows array. JSON bukan SQL dump. Timestamp masa depan lebih dari 5 menit ditolak; timestamp sama atau lebih lama dari watermark batch yang pernah diterima ditolak pada impor biasa.

source_instance/scope: ASCII A-Z a-z 0-9 _ . : / - maksimal 128 karakter. Konfigurasi importer memilih tepat satu pasangan sumber/cakupan agar dua full snapshot yang overlap tidak dihitung bersama. Jangan mengubah scope untuk menyamarkan snapshot parsial. Setiap kode asli disertakan sebelum grouping lintas kode. Grain versi ini adalah kode sumber setelah TRIM/case-insensitive + expired_date; beberapa LOT internal Zahir dalam grain yang sama harus diagregasi exporter secara eksplisit. Importer menolak grain ganda.

Rows memiliki kode_barang string ASCII maksimal 25 karakter (huruf, angka, spasi, _ . : / -), nama_barang string UTF-8 nonkosong maksimal 65535 byte, expired_date YYYY-MM-DD atau null, qty_lot STRING desimal bertitik tanpa eksponen maksimal 18 digit bulat + 6 pecahan, p/l/t integer atau string integer. Batas integer aplikasi aktual 1-999 untuk aktivasi snapshot; dimensi adalah P*L*T, maksimum 997002999 sehingga muat signed INT. Tanggal null/kosong dan ukuran kosong/0/pecahan dilaporkan sebagai error dan menahan aktivasi. Tidak ada pembulatan atau pemotongan. Kode di luar subset ASCII ditolak secara eksplisit sampai audit aturan identitas/collation baru. Nama dibersihkan dari * dan spasi dirapikan untuk master/katalog; nama sumber asli tetap disimpan.

DECIMAL(24,6) menampung nilai absolut sampai 999999999999999999.999999. Bukti kecukupan adalah batas validator tersebut; ini bukan klaim bahwa domain Firebird sudah diperiksa langsung. Perluasan domain harus menaikkan versi kontrak atau diaudit sebelum migrasi. Qty nol/negatif wajib disertakan oleh exporter; importer mempertahankannya. Snapshot kosong atau parsial tidak bisa diaktifkan melalui alur biasa. Hash SHA-256 mendeteksi kesamaan bytes, bukan keaslian exporter.

CSV didukung sesuai keputusan pengguna tanggal 9 November 2026: header persis kode_barang,nama_barang,expired_date,qty_lot,p,l,t. Metadata yang sama diisi operator pada formulir dari laporan exporter, bukan ditebak dari nama file/waktu upload. row_count wajib diisi sebelum validasi. Tanggal kosong menjadi error; angka diparse sebagai teks. CSV tidak diedit/digabung manual. UUID, source_instance/scope, exported_at dan pernyataan full/complete harus disediakan pihak exporter secara tepercaya. CSV yang sama dengan UUID atau metadata berbeda ditolak sebagai konflik pengiriman ulang. Pengiriman ulang identik pada batch aktif tidak menggandakan data. Pengiriman batch historis harus memakai pemulihan terpisah.

Batas 5 MiB dan 10000 baris mencakup seluruh file. UTF-8 BOM diterima. Contoh JSON dan CSV di folder ini sintetis, bukan data bisnis atau bukti ekspor terbaru. exported_at contoh sengaja tetap; ganti dengan waktu ekspor sesungguhnya saat membuat ekspor baru.
